# QA 체크리스트 — 채팅 개편 · 인프라 핫픽스

최근 작업(채팅 리디자인 → 2/3분할 → 실시간/성능 → 하이드레이션·알림 핫픽스)의 수동 검증 시나리오.
구현은 빌드·타입·라우팅까지만 검증됐고 **로그인 뒤 화면·실시간·타이밍은 미검증**이므로, 아래 항목은 사람이 직접 확인한다.

## 환경 · 유의
- **가능하면 프로덕션 빌드(`npm run build && npm start`)에서 검증.** `npm run dev`는 ① Link 프리페치가 꺼져 있고 ② 라우트를 클릭 시점에 온디맨드 컴파일해, 방 전환·초기 로딩이 실제보다 느리게 느껴진다.
- 실시간·유저 간 테스트는 **서로 다른 브라우저/시크릿창에 다른 계정**으로 로그인해 진행.
- 우선순위: **P0** = 이번에 고친 핵심(회귀 시 치명), **P1** = 주요 UX, **P2** = 부가.
- 결과 칸에 `Pass` / `Fail(메모)` 기입.
